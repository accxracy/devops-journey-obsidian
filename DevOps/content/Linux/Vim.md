# 🥷 Neovim (NvChad) Cheat Sheet

## 🟢 1. База (Выживание)

|            |                                                         |
| ---------- | ------------------------------------------------------- |
| Кнопка     | Действие                                                |
| `Esc`      | Выйти в Командный режим (Normal Mode) из любого другого |
| `:q`       | Выйти / Выйти принудительно (без сохранения)            |
| `:w`       | Сохранить файл                                          |
| `u`        | **Undo** (Отменить последнее действие)                  |
| `Ctrl + r` | **Redo** (Вернуть отмененное)                           |

## 🧭 2. Навигация (Без стрелочек)

|   |   |
|---|---|
|Кнопка|Куда прыгаем|
|`h` `j` `k` `l`|Влево, Вниз, Вверх, Вправо|
|`w`|Прыжок на начало следующего слова|
|`b`|Прыжок на начало предыдущего слова|
|`0` (ноль) / `^`|В самое начало строки / К первому символу строки|
|`$`|В самый конец строки|
|`gg`|В самое начало файла (на первую строку)|
|`G` (Shift + g)|В самый конец файла (на последнюю строку)|

## ✍️ 3. Редактирование (Вход в Insert Mode)

|   |   |
|---|---|
|Кнопка|Где начнем печатать|
|`i`|Прямо перед курсором|
|`a`|Сразу **после** курсора (удобно в конце слов)|
|`A` (Shift + a)|В самом **конце** строки|
|`o`|Создаст пустую строку **ниже** и переведет туда курсор|
|`O` (Shift + o)|Создаст пустую строку **выше** и переведет туда курсор|

## ✂️ 4. Копирование, Вырезание, Вставка

> **Словарь Вима:** `y` (Yank - копировать), `d` (Delete - вырезать), `p` (Put - вставить).

|   |   |
|---|---|
|Кнопка|Действие|
|`v` / `Shift + v`|Обычное выделение / Построчное выделение (Visual Mode)|
|`y` / `yy`|Скопировать выделенное / Скопировать строку целиком|
|`d` / `dd`|Вырезать выделенное / Вырезать строку целиком|
|`p` / `P`|Вставить после курсора / Вставить до курсора|
|`"+y`|Скопировать в **системный** буфер (чтобы вставить в ТГ/браузер)|

## 🧙‍♂️ 5. Магия Вима (Текстовые объекты)

|   |   |
|---|---|
|Комбинация|Что делает (Магия)|
|`c i "`|Удалит всё внутри кавычек `""` и сразу включит режим ввода|
|`d i (`|Удалит всё внутри круглых скобок `()`|
|`v i {`|Выделит весь блок кода внутри фигурных скобок `{}`|
|`c i w`|Изменит слово, на котором сейчас стоит курсор|

## 🚀 6. Фишки NvChad (Пробел = Leader Key)

|   |   |
|---|---|
|Комбинация|Действие|
|`Пробел + e`|Открыть/Закрыть дерево файлов (Explorer)|
|`Пробел + f + f`|Быстрый поиск файлов (Telescope)|
|`Пробел + f + w`|Глобальный поиск слова по всем файлам проекта|
|`Пробел + t + h`|Выбрать красивую тему оформления (Theme)|
|`Пробел + x`|Закрыть текущую вкладку (файл)|
|`Tab` / `Shift + Tab`|Переключаться между открытыми вкладками сверху|
|`Ctrl + h` / `Ctrl + l`|Прыгать между окном Проводника и окном Кода|
